dylib hijacking macos

52 min · Patrick Wardle · DEF CON 34 session · high

Dylib hijacking still works on modern macOS: plant a version-matched, re-exporting malicious dylib in a third-party app’s primary rpath (e.g. Photoshop’s libtbb); Apple’s app protection and re-validation miss it, so you get stealthy code exec with the host’s TCC/network rights.
